A01

스플래시

로그인 · 온보딩

이렇게 만들었어요

  • 화면 문구는 피그마 최종본(11/6)을 그대로 썼어요. 그림은 와이어프레임 모양으로 다시 그렸어요.
  • 피그마에 없어서 채운 글 옆에는 작은 회색 글씨로 (임의)를 붙였어요.
  • 위시카드 · 투표 · 토너먼트 결과는 눌러 본 대로 이어져요. 남은 시간 · D-day · 퍼센트도 그때그때 계산돼요.
  • 날짜는 피그마와 같은 '11. 5. (수)' 기준이에요.
  • 친구 화면은 왼쪽 「친구 화면」에서 열어요. 친구가 투표하면 내 위시카드에 바로 반영돼요.

피그마끼리 다른 곳 (앱에서 고른 쪽)

  • 하단 탭: A · C는 '위시리스트', 로그인 E01 · MY는 '위시' → 앱은 '위시리스트'
  • 위시리스트 첫 화면: E01과 W01-a 문구가 달라요 → 앱은 W01-a
  • 카테고리: A는 6개, C-W07에 '신발', C-W15a는 8개 → 각 화면 그대로 둠
  • C-W02 · C-W03 뒤 화면: 피그마는 옛 A 홈 → 앱은 지금 W01 위에 띄움
  • '결정 완료'(B)는 공통 프롬프트 금지어 · A '안 사기로 함'과 C '포기'가 섞여 있어요
  • 알림 설정: '클릭 타이머 종료' 오타가 그대로 있어요
  • 토너먼트 기간: T03은 '5일', T07 설명은 '24시간'
  • MY 닉네임: '으누' / '은우'가 섞여 있어요

피그마에 없어 채운 글 · 화면에 (임의)로 표시

  • WORST 공동 1위 · 종료 화면 제목 (피그마엔 BEST만)
  • '안 사기로 기록했어요' (토너먼트 · 목록 줄, 피그마엔 '구매로'만)
  • 👎가 더 많을 때 결정 시트 문장 (피그마엔 👍만)
  • 리포트 탭 목표 줄 '지금 포기 비율 · 직접 연장 · 투표 받은 위시카드' (피그마엔 카테고리만)
  • C-W15 패션·잡화 말고 다른 카테고리의 '10월 ○○ 구매 N개' 숫자
  • 토너먼트 첫 판 '8강' · '결과 없음' 줄 설명 · 여행 가방 결정 완료 화면
  • 카카오 동의 화면 맨 위 글 · 약관 전문의 '개인정보 수집·이용 동의' 제목
  • 예시 친구 닉네임 '지호' · '다은' · 지운 후보 '지운 위시카드'
  • 토너먼트 결정 뒤 메모 시트 · 두 번째부터의 24시간 연장 · 알림 잠금 · 편집 '저장 중'

글이 아니라 화면에 표시 못 한 것

  • 홈 화면 추가 안내의 X → D08 (피그마 D02 설명은 'X → D10', D08 설명은 'X → D08')
  • 중복 닉네임 예시는 '야르렁'만 (가입 C05 예시 '은우'를 막으면 기본값으로 가입이 안 돼요)
  • 친구 화면 주인 이름 = 가입한 닉네임 (피그마 '지우') · MY '으누' 대신 '은우'
  • 공개 범위는 처음에 고를 수 있는 항목 전부 체크 · '마감 임박' = 24시간 안 남았을 때
  • 예시 위시카드(가을 셔츠 · 백팩 · 스마트워치) 남은 시간, 텀블러 · 러닝화 등 카테고리, 등록 날짜
  • 날짜 · D-day는 눌러 본 시각 기준 계산 (피그마 D-3 → 앱 D-5 등)
  • 리포트 탭 그래프 막대 높이 · 화면 색(칩 색 등)은 다시 그리면서 정함
  • 9월 리포트 줄은 카드 데이터가 없어 C-W17로 바로 열려요 · 예시 토너먼트(주방 가전 · 운동화 · 여행 가방)는 피그마 예시 화면 내용으로 열려요

문의 · 수정 요청은 혁주에게. 이 페이지는 팀 피그마(읽기만)에서 문구를 가져왔어요.
